# Victor Quaint — Portfolio (May 2024 Web Hackathon)

Personal portfolio website ("Victor Quaint") built for the May 2024 web
hackathon.

## Overview

Static portfolio site showcasing profile, skills, and projects. Forked from the
hackathon starter repository.

## Tech Stack

- JavaScript
- HTML & CSS

## Getting Started

Open `index.html` in a browser, or serve the folder with any static server:

```bash
npx serve .
```
